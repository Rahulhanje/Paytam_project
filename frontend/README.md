# Frontend

## Project Overview

This project is a frontend application built using React, Tailwind CSS, and Vite. It provides a user interface for managing financial transactions, including:

* **Dashboard**: Displays a summary of the user's financial information.
* **Send Money**: Allows users to transfer funds to other accounts.
* **Sign In/Sign Up**: Provides authentication functionality.

## Features

* **User interface**: A clean and intuitive user interface built with React and Tailwind CSS.
* **Financial management**: Enables users to view account balances, send money, and manage their finances.
* **Authentication**: Securely verifies user identities for access to sensitive financial data.
* **Responsive design**: Adapts to different screen sizes for optimal viewing on various devices.

## Installation

1. Install Node.js and npm: [https://nodejs.org/](https://nodejs.org/)
2. Navigate to the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

1. Start the development server:
   ```bash
   npm run dev
   ```
2. Open [http://localhost:5173/](http://localhost:5173/) in your browser.
